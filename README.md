# PicBatchKit · 批量图片处理

**[👉 打开网页版 · 图片压缩裁剪小助手](https://dimoo-rich.github.io/PicBatchKit/)**

无需下载或安装，打开即可批量压缩、裁剪和统一图片尺寸。

一个在本地处理图片的小网页，以及用于自动批量处理的 Codex Skill。适合发布前统一配图比例、尺寸和文件体积。

## 功能

- 3:4 / 1:1 居中裁剪，或白色留边保留完整画面
- JPG、PNG、WebP 格式转换，指定目标文件大小
- 批量处理、调整顺序、01 / 02 顺序命名
- 单张下载或 ZIP 打包，附处理报告
- 全部图片处理在本地完成，网页无第三方脚本、无图片上传接口

## 网页使用

在线使用：[打开网页版](https://dimoo-rich.github.io/PicBatchKit/)，无需下载或安装。

也可以下载源码，用现代浏览器打开 `index.html`，静态文件无需构建和安装依赖。仓库根目录可部署到支持 HTML 的静态托管服务。

使用流程：添加图片 → 选择比例与处理方式 → 处理全部图片 → 检查预览 → 下载。

## Skill 使用

解压 `image-compressor-skill.zip`，将 `image-compressor` 文件夹复制到自己的 `~/.codex/skills/` 目录。

示例：使用 $image-compressor 把这些图片整理成 3:4 配图，每张小于 1 MB，按顺序打包，保留原文件。

需要 Python 3 和 Pillow。依赖见解压后的 `image-compressor/requirements.txt`，详细参数见包内 SKILL.md。

## 隐私与限制

图片不上传服务器。访问线上网页本身仍经过托管服务，可能产生访问日志。无需账号。

默认 1200 像素和 1 MB 是工具预设，不是平台官方上传限制。本项目与小红书无隶属关系。

居中裁剪可能切掉主体；小图放大不能增加细节；超过体积目标时可能继续缩小尺寸。透明图转 JPG 变为白底。动态图仅输出第一帧。HEIC 不支持。手机 ZIP 下载后需要解压；尚未完成网页版手机真机验证。
